Haunted Race

Unity - Google Play - Firebase

👻 Haunted Race is a mobile game I developed and published for Android devices. It’s an infinite runner where a ghost races through a procedurally generated castle, dodging enemies and collecting perks along the way. 📱 The gameplay is designed specifically for touchscreen controls. 🧩 Each run is unique thanks to random generation of maps, enemies, and power-ups. 🛠️ Haunted Race is a fully finished product, published on the Google Play Store to gain hands-on experience with the entire release pipeline. Aside from sound effects, all assets—sprites, animations, code, UI, and systems—were created from scratch. Key features include: -Scene transitions and sound management -Local data storage -Touchscreen input handling -Animation systems -Post-launch patching and bug fixes ☁️ One of the most important features is online data saving using Firebase: - Players can submit their best score after each run. - The game checks if the score qualifies for the top 100 global leaderboard. - If it does, the lowest score is removed and replaced with the new one. - Players can view their personal best and the current top 100 rankings from the main menu. Haunted Race was published on the Google Play Store to gain experience with a real mobile deployment and post-launch updates.

The wizard's labyrinth

Unity - Windows - Random map creation module

🎮 The Wizards' Labyrinth is a game I developed in Unity, centered around navigating procedurally generated labyrinths. The player must find the exit while avoiding enemies that use NavMesh for intelligent pathfinding and obstacle avoidance. 🧩 The core feature of this project is a random map generation module, which I designed as a standalone system that can be easily integrated into other Unity projects. This module: - Creates unique labyrinth layouts for every playthrough. - Automatically places enemies and key elements without spatial conflicts. - Guarantees that a valid path to the exit always exists. This project demonstrates my ability to build reusable systems, work with procedural content generation, and implement AI-driven navigation in dynamic environments.

Triangle Strategy Grid Movement

Unity - Windows - A* Pathfinding implementation for movement

🧠 While playing Triangle Strategy on the Nintendo Switch, I was inspired by its tactical depth and decided to recreate some of its core mechanics in Unity—specifically its grid-based movement system. 🔍 To achieve this, I implemented the A search algorithm* from scratch. This algorithm calculates the shortest path between two points on a graph, making it ideal for turn-based movement across a grid. 🧪 The result is a proof of concept in Unity where: - Each unit has a movement value that determines how many nodes it can traverse per turn. - Reachable cells are highlighted in pink, based on the unit’s position and the A* pathfinding logic. - A simple turn-based and attack system adds functionality and demonstrates the concept in action. The proof of concept showcases my ability to translate complex gameplay mechanics into functional prototypes, as well as my understanding of pathfinding algorithms and turn-based systems.
